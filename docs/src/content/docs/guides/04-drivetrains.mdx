A `Drivetrain` is a type of [Attachment](../02-attachments) that defines [Actions](../../concepts/01-actions) that can move [Robots](../01-robots) autonomously and tele-operated.

## Steps

Volt provides many pre-built `Drivetrain` classes for many combinations of drivetrain types, localization methods, and backends. Using these pre-built classes is the simplest way to add a `Drivetrain` to your [Robot](../01-robots).

:::note

It is also possible to implement a custom `Drivetrain` class by extending one of the provided abstract classes. This guide assumes you will use one of the pre-built `Drivetrain` classes seen in the table below.

:::

:::tip[Prerequisites]

This guide assumes you've [created a Robot class](../01-robots), [created an Attachment class](../02-attachments), and [learned to use built-in Attachments](../03-built-in-attachments).

:::

### 1. Choose a `Drivetrain`

Choosing a `Drivetrain` is a three-step process:

1. Select a type of physical drivetrain (What drivetrain does your robot physically use?)
2. Select a localization method (What localization hardware do you have?)
3. Select a compatible backend (Which pathing backend/actions do you want to use?)

:::note[See Also]

See [RoadRunner vs PedroPathing](../../reference/drivetrain-backends) to decide which backend is best for you.

:::

### 2. Create a `DrivetrainRobot`

Create a `Robot` class that extends `DrivetrainRobot`. This gives your [Robot](../01-robots) access to a `drivetrain` instance.

<Tabs syncKey="language">

<TabItem label="Kotlin">

```kotlin "DrivetrainRobot"
class MyRobot(hardwareMap: HardwareMap) :
    DrivetrainRobot(hardwareMap)
```

</TabItem>

<TabItem label="Java">

```java "DrivetrainRobot"
public class MyRobot extends DrivetrainRobot {
    public MyRobot(HardwareMap hardwareMap) {
        super(hardwareMap);
    }
}
```

</TabItem>

</Tabs>

### 3. Declare `Drivetrain` Type

Pass a generic type parameter that inherits `Drivetrain`. This lets Volt know what type of `Drivetrain` class your [Robot](../01-robots) uses.

In this case we'll use `PinpointMecanumPedroPathingDrivetrain`:

<Tabs syncKey="language">

<TabItem label="Kotlin">

```kotlin "<PinpointMecanumPedroPathingDrivetrain>"
class MyRobot(hardwareMap: HardwareMap) :
    DrivetrainRobot<PinpointMecanumPedroPathingDrivetrain>(
        hardwareMap,
        PinpointMecanumPedroPathingDrivetrain(
            hardwareMap,
        )
    )
```

</TabItem>

<TabItem label="Java">

```java "<PinpointMecanumPedroPathingDrivetrain>"
public class MyRobot extends DrivetrainRobot<PinpointMecanumPedroPathingDrivetrain> {
    public MyRobot(HardwareMap hardwareMap) {
        super(getHardwareMap(), new PinpointMecanumPedroPathingDrivetrain(
            getHardwareMap()
        ));
    }
}
```

</TabItem>

</Tabs>

### 4. Create and Configure `Drivetrain` Instance

Create a new instance of your `Drivetrain` type. This is where you define hardware and tune your `Drivetrain`.

:::tip

Learn how to tune your robot on the [Tuning Your Robot](../../reference/tuning) page. Constants vary with each `Drivetrain` implementation.

:::

For our `PinpointMecanumPedroPathingDrivetrain`, we'll supply `PinpointConfig`, `MecanumConfig`, and use the `Foresight` algorithm.

<Tabs syncKey="language">

<TabItem label="Kotlin">

```kotlin {6-62}
class MyRobot(hardwareMap: HardwareMap) :
    DrivetrainRobot<PinpointMecanumPedroPathingDrivetrain>(
        hardwareMap,
        PinpointMecanumPedroPathingDrivetrain(
            hardwareMap,
            PinpointConfig {
                it.name.set("pinpoint")
                it.xPodOffset.set(2.187)
                it.yPodOffset.set(-4.572)
                it.xPodDirection.set(GoBildaPinpointDriver.EncoderDirection.FORWARD)
                it.yPodDirection.set(GoBildaPinpointDriver.EncoderDirection.FORWARD)
            },
            MecanumConfig {
                it.frontLeftName.set("lf")
                it.backLeftName.set("lr")
                it.frontRightName.set("rf")
                it.backRightName.set("rr")

                it.frontLeftDirection.set(DcMotorSimple.Direction.FORWARD)
                it.backLeftDirection.set(DcMotorSimple.Direction.FORWARD)
                it.frontRightDirection.set(DcMotorSimple.Direction.REVERSE)
                it.backRightDirection.set(DcMotorSimple.Direction.REVERSE)

                it.manualBrakeMode.set(true)
            },
            Foresight(
                ForesightConfig {
                    val primaryTranslationalForward = Controller.proportional(0.3)
                    val secondaryTranslationalForward = Controller.proportional(0.1)
                    val primaryTranslationalLateral = Controller.proportional(0.3)
                    val secondaryTranslationalLateral = Controller.proportional(0.1)

                    it.forwardTranslational.set(
                        Controller.piecewise(secondaryTranslationalForward)
                            .put(2.5, primaryTranslationalForward)
                    )
                    it.strafeTranslational.set(
                        Controller.piecewise(secondaryTranslationalLateral)
                            .put(2.5, primaryTranslationalLateral)
                    )

                    it.coast.set(Controller.proportionalFeedforward(0.010978350889324107))
                    it.brake.set(Controller.proportionalFeedforward(0.008731598255925491))

                    it.headingFeedback.set(Controller.proportional(5.258721785960744))
                    it.headingBrakeCoefficients.set(
                        Vector2D.cartesian(0.05642143125655298, 0.0063829525363003695)
                    )

                    it.linearBrakeCoefficients.set(
                        Matrix.diag(0.10605894992901523, 0.08719146175596092)
                    )
                    it.quadraticBrakeCoefficients.set(
                        Matrix.diag(0.0014663966976606565, 0.0013837064502458813)
                    )

                    it.maxAchievableForwardVelocity.set(72.72923108818539)
                    it.maxAchievableStrafeVelocity.set(52.34323936525474)
                    it.naturalForwardDeceleration.set(85.01144677379789)
                    it.naturalStrafeDeceleration.set(104.49787535782846)
                }
            ),
        ),
    )
```

</TabItem>
